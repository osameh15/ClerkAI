## Summary

Converts multimodal teaching material — audio, video, slides (PPTX/PDF), handouts, images and text — into educational Knowledge: concepts, definitions, examples, key points, questions and concept relationships, then study notes and flashcards. Strong support for Persian and mixed Persian/English slide-plus-audio content; **source-grounded** by default.
