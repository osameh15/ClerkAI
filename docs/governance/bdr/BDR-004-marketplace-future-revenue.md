# BDR-004: Marketplace Data Model from Day One; Third-Party Execution Later

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-09 (Blueprint v1.0) |
| Deciders | Founder, Technical Leadership |
| Blueprint | BP §5.2, §23, §28.3 |

## Decision

Publisher, Listing, ModuleVersion, pricing metadata and review status exist in the data model and contracts from v1. The only v1 publisher is `clerk-official` (Marketplace stage M0). Partner declarative modules (M1), remote modules (M2), public SDK with revenue share and payouts (M3) and ranking/reviews (M4) follow on demand. Marketplace revenue share is a later revenue stream.
