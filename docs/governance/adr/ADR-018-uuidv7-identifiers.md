# ADR-018: UUIDv7 Identifiers

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-09-28 |
| Deciders | Technical Leadership |
| Blueprint | BP §7.2 |

## Decision

Primary keys of business entities are **UUIDv7**, generated by the application (Go) at creation time — not by database defaults — so IDs are known before insert (useful for outbox events and object keys). Time-ordering improves B-tree locality. High-volume append-only tables (for example `usage_events`, `audit_events`, `outbox_events`) may use an internal `BIGINT` identity plus an external UUID. Details and exceptions: [identifier-strategy](../../data/identifier-strategy.md).

## Consequences

UUIDv7 leaks creation time at millisecond precision; acceptable because authorization never relies on ID secrecy ("possession of an ID is never authorization", BP §14.2).
