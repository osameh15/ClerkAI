# PDR-005: Transcript Is Not the Primary Meeting Output

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-09 (Blueprint v1.0) |
| Deciders | Product |
| Blueprint | BP §3.1, §28.2 |

## Decision

For Meeting Minutes the primary outputs are structured Knowledge (Decision, Action, Owner, Deadline, Risk, Open Question) and the formal Minutes Artifact. The transcript is a secondary, supporting output (an Extraction of the audio Source) used as Evidence and optionally viewable.

## Consequences

Evaluation focuses on extraction precision/recall and evidence, not only WER. UX leads with minutes and actions; the transcript is a side panel.
