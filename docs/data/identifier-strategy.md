## Rules

| Kind | Format | Generated by | Notes |
|---|---|---|---|
| Business entity IDs | UUIDv7 | Go (`platform/ids`) before insert | Canonical lowercase hyphenated string in APIs ([ADR-018](../governance/adr/ADR-018-uuidv7-identifiers.md)) |
| High-volume append tables (`usage_events`, `audit_events`, `outbox_events`, `webhook_deliveries`) | internal `BIGINT GENERATED ALWAYS AS IDENTITY` + external `UUID` (UUIDv7) | DB / Go | External UUID exposed; BIGINT never exposed |
| Stable keys | `key TEXT` | Humans/manifests | Modules (`business.meeting-minutes`), permissions (`artifacts.export`), entitlements (`export.docx`), prompts (`meeting.action-extraction`), profiles (`persian_transcription`), plans (`team`) |
| Versions | SemVer strings for modules, prompts, schemas, public events use integers; DB ordinal `version INT` for plan/template/workflow/config versions | | |
| `request_id` | UUIDv7 string | API | Returned as `X-Request-Id` |
| `correlation_id` | UUIDv7 string | First entry point | Propagated end-to-end |
| Temporal IDs | Deterministic string from business IDs | API/worker | `job/{job_id}/run/{run_no}` ([temporal-workflows](../jobs/temporal-workflows.md)) |
| Offline temporary IDs | `tmp_` + client UUIDv4 | PWA | Mapped to server IDs on sync via `client_ref` ([synchronization](../pwa/synchronization.md)) |
| API keys | `ck_live_<prefix8>_<secret>` / `ck_test_…` | API | Prefix stored plain for display; secret hashed ([api-keys](../api/api-keys.md)) |
| Document numbers | Template pattern (for example `SR-1405-0042`) | Numbering sequence | Business identifier, not a key ([numbering-sequences](../artifacts/numbering-sequences.md)) |

## Exceptions

- `permissions.key`, `entitlement_definitions.key` are text primary keys (stable vocabulary).
- Join tables use composite primary keys.

## Security Note

IDs are not secrets. Possession of an ID never grants access (BP §14.2); every access is authorised.
